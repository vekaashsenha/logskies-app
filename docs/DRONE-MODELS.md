# Drone model selection

Web Add drone offers a model dropdown, existing organization model names, and Other / custom model. This saves into the existing model_name field; no migration is required. Multiple aircraft can share a model and use separate UINs. Android displays the same saved records; creation continues through web.

The initial names were checked on manufacturer pages, not a government certification register. Listing is inventory convenience, not parser compatibility, certification or endorsement.
