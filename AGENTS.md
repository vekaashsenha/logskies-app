# LogSkies cross-platform changes

For feature, terminology or workflow changes, review both the web app and Android app, shared API/domain code, reports, relevant solutions/features/integrations content, FAQ, privacy disclosure and validation docs. Update every affected surface together; preserve accurate limitations where functionality differs.

Website deployment does not update an installed Android APK. Native changes require a new tested preview/release artifact. Clearly distinguish committed code, deployed web behavior, built APKs and physical-device validation. Never call a report DGCA-approved or audit-proof without verified acceptance evidence.

See docs/PLATFORM-UPDATES.md and applicable app-level AGENTS.md instructions.
